This site is built using Astro, then served over Caddy on my own web hosting service, Love Computer.

### design

I'm using Tailwind CSS for styling as it works nicely with my brain.

The colour-scheme is [uchu](https://uchu.style). (tf2 heavy voice) is nice.

Fonts in use are IBM's Plex Sans, and [US Graphics Co.](https://usgraphics.com/)'s Berkeley Mono.

Icons are provided by Font Awesome. [^1]
